## 4. 方法（下一轮怎么补 E0，直接可执行）

1. **招募**：通过公开病友社群/医院社工渠道招募 3–5 位（肢体术后 2、腹膜后 1、晚期换线 1、家属代记 1）。
2. **访谈提纲**（30 分钟，围绕"最近一次复查前你在做什么"）：
   - 你最近一次拿到报告，第一眼看的是哪一行？为什么？
   - 你怎么知道这次要和哪次比？
   - 家里谁在记这些？记在哪？
   - 你有没有把两张报告摊在一起看过？当时想解决什么？
3. **记录**：逐字稿 + 场景卡（原话 / 触发 / 想要的结果 / 现在怎么凑合）。
4. **落库**：E0 结果回填本文件 §3，把"假设"改成"已确认/已证伪"，并在 `SCENARIOS.md` 更新原话来源标注。
