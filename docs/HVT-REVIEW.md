## 1. 方法与口径

- 疾病轴差异（相对移植底本 cervical-workbench）：① 亚型有 11 类/约 70 种、且患者最先拿到的是亚型词；② 部位决定分期组与随访路径；③ 局部与全身治疗常同期并行；④ 影像无贯穿数值指标；⑤ 术后功能与淋巴水肿是长期主诉；⑥ 生育与性功能在高龄化工序下是真实议题。
- 打分：V/S/F 各 1–3；HVT 门槛 V≥2 且 S≥2；优先级 P = V×S×(5−C)。
- 五层：S 场景、M 模块、F 字段、I 交互、A 验收 各 0/1。
- C（成本）为本代理人工判读，非脚本输出；脚本只给结构计数。

## 4. 差异评价

### B1 亚型枚举的诱惑

- 现象：初始 SPEC 写"STS 亚型 50 余种"，且 schema 里 `pathology` 表曾以 `depth` 命名深浅。
- 证据：`research/medical/MEDICAL-CONSTRAINTS.md` §1.3（WHO 不公布总数；"约 70"出自 Pathologica 2021 综述）与 §2.3（AJCC 第 8 版已取消 T 深浅 a/b，第 7 版才有 T1a/T1b）。
- 影响：若照抄"50 余种"并做下拉枚举，患者会被诱导"选择=自动分类"，而分类是病理科综合判断；若把"深浅"挂在 AJCC 8 T 上，会输出医学上不存在的分期依据。
- 处置：已改文档（P1、P2 已并入）。

### B2 影像数值趋势的诱惑

- 现象：家族有"病情一图秀"结构，容易被复制成"病灶大小折线"。
- 证据：`CLINICAL-DATA.md` §4（RECIST 是研究口径）；`research/medical` §6.2 同结论。
- 影响：自算变化率等于做了医生的判读工作（违反 K1、K4）。
- 处置：ADR-3 明确不做数值趋势，只做基线锚点 + 原文并列（P3 已并入）。

### B3 随访间隔被读成指令

- 现象：拿到"3–6 个月"就想做成倒计时/逾期提醒。
- 证据：`research/medical` §5.3（UK 2016 明确写 STS 随访缺乏高质量证据、各中心差异大）；§5.1（NCCN 专业版未取得，只有患者版）。
- 影响：患者会以为"逾期=恶化"，且这个数字本身不是共识。
- 处置：只显示"距上次 X 个月 + 参考值 + 出处"，禁词表加"你该去复查了/已逾期"（P4 已并入）。

### P2 深浅 → 并入 DEV-REQUIREMENTS H3、SPEC schema

> 字段改名 `depth_text`；界面出现"深浅"时必须同时出现"影像/手术描述"或"第 7 版口径"。

判据：schema 无 `depth` 裸字段；H3 条款含"不挂 AJCC 第 8 版 T"字样。实测通过。

### P3 影像 → 并入 SPEC ADR-3

> 不做病灶数值趋势；只做基线锚点（每部位 ≤1 激活）与原文并列对照；报告词表只解释不判读。

判据：① 原型无病灶大小折线（只有单指标趋势，且指标来自化验单）；② `test/demo-data.test.mjs` 断言每部位基线数 == 1；③ 影像记录无 recist/response/progression 字段。三项实测通过。

### P4 随访 → 并入 CLINICAL-DATA §6

> 只显示"距上次复查 X 个月"+ 公开参考间隔 + "患者版转述"标注 + "由医生按个人情况决定"。

判据：禁词「你该去复查」「已逾期」0 命中。实测 0（首次运行曾命中 1 处描述性文案，已改写）。

### P5 AI 通道 → 并入 INTERACTION-DESIGN IP9/IP10

> AI 只产出候选，不经确认不入档；拒收零副作用；trials 条目禁止 AI 生成。

判据：原型 AI 按钮点击后只渲染候选卡 + toast"未自动发送"；候选卡含「全部拒收（零副作用）」。实测通过。
