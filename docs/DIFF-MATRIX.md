## 一、软组织肉瘤的差异化种子（7 条）

1. **非计划切除（unplanned excision / "whoops"）是肉瘤独有的确诊创伤**：无痛肿块被当作脂肪瘤/囊肿切掉，
   术后病理才回报肉瘤，于是要二次扩大切除。瘤床残留率约 50%–60%（Grimer 2019 综述；Larios 综述 n=16,946）。
   → 界面只记「哪天在哪做过什么、病理什么时候回报」，**绝不评价当初该不该切**（属判断，H 清单第 4 条）。
2. **部位决定一切，而且「有的部位根本没有分期」**：四肢/躯干、腹膜后、头颈、胸腹腔内脏、眼眶各有规则；
   AJCC 8 里**头颈、胸腹腔内脏、眼眶未定义分期组**（NCCN ST-5 原文：needs data collection before
   defining a stage grouping）。→ 分期页签必须能空着并写明「该部位 AJCC 8 未定义分期组」，不许补一个期别。
3. **分级 ≠ 分期 ≠ 亚型，且分级是分期的输入**：FNCLCC = 分化(1–3)+核分裂(1–3)+坏死(0–2)=2–8 分，
   G1=2–3 / G2=4–5 / G3=6–8；G 参与构成 AJCC 分期组。→ 三个词分开摆、可并列说明关系，
   **不许互推**（产品算出 G 或补出期别都属判断，H 清单第 1、2 条）。
4. **切缘是肉瘤的核心病理字段**：R0/R1/R2 + 边界类型（CSCO 共识另有四型边界口径）。
   → 只抄病理原文，不解释「切干净了没有」（H 清单第 3 条）。
5. **复发监测因部位而异，随访节奏按「分期组 + 可切除性/功能结局」分五档**（NCCN V3.2026 原表五档）。
   四肢/躯干以肺转移为主（>70%），腹膜后以局部/腹膜内复发为主，且高分化脂肪肉瘤不需常规胸部影像
   （RETSARC-3 脚注 r）。→ 页面只并列「我这次做了哪些检查」，**不推导转移规律、不排计划**。
6. **功能与康复是肉瘤术后的一条主线，但量表必须分开处理**：MSTS 是**医生填**（CROM）→ 产品不给；
   TESS 是**患者自评**（PROM，下肢 30 项 / 上肢 29 项）→ 可记原始作答与日期，
   **但分数解读与变化趋势属医学判断，不生成**（H 清单第 10 条）。
7. **「该不该去专科中心」不能说，但「在哪看的、是否 MDT」可以记**：NCCN 明确要求治疗前由肉瘤
   多学科团队评估（RETSARC-1 原文）。→ 记机构名与是否 MDT（事实），**不生成「你应该转院」**。

## 四、G1 决策点（要用户拍板的）

1. **品牌名**：工作名「小韧宝 SarcPal」（G1 拍板）。家族有定名改三次的教训，须由用户定。
2. **覆盖范围**：默认排除 GIST（已独立建仓 `gist-workbench`）、骨肉瘤/骨巨细胞瘤（骨癌线）、
   卡波西肉瘤、硬纤维瘤（中间型，非恶性）。是否收下？
3. 「确诊路径」独立成一级页（3 页签）是否过度？——它承载肉瘤最强的差异化，但只服务"走过弯路"的那批患者。
4. 「功能与康复」独立成一级页 vs 并入「生活与照护」？
5. TESS 自评做到哪一层：只记日期与"填了/没填"，还是记 30 题原始作答？（后者字节大、且不能给分）
6. 「放疗」放「治疗与线序」页签 vs 独立一级页？（术前/术后放疗是肉瘤标准路径之一，但不人人做）
7. 分子检测页签做多深：只记"做了哪些检测、结果原文"，还是含"哪些亚型该查什么"的解释？
   （解释属第②层，须有机构+版本+页码；本轮 NCCN SARC-C 未提取原文 → **默认只记不解释**）
8. 遗传与家系（NF1 / Li-Fraumeni 等）做不做？倾向**不做独立页**——遗传易感性判定属判断（H 清单第 13 条），
   只在「我的肿瘤 → 分子检测」里记"做过哪些检测、报告原文"。
9. 「临床研究」一级页是否收进 G1 范围？（肾癌 G1 决策点 7 的同款问题：不收则采集数据孤儿）
10. 「影像与报告 → 资料整理」页签（上传→解析→核对→入库）是否收进 G1 范围？（同上，原型演示流）
