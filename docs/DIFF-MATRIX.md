# 软组织肉瘤工作台 · 差异化矩阵（DIFF-MATRIX）v0.1

> 状态：草案（G1 待签认）。目的：证明本仓**不是把 cervical 或 breast 换标题**。
> 口径：26 号 §4.1 ——「任意两个癌种的一级名称一致率 > 70% 且二级顺序一致 → 没有认真做本癌种调研」。
> 实测方法与原始数据见 §2；**数字是脚本实测，不是估计**。

## 1. 结论（先给数）

| 对比基准 | 基准一级数 | 本仓一级数 | **逐字同名字** | **一级名称一致率** | Jaccard |
| --- | --- | --- | --- | --- | --- |
| `cervical-workbench` v0.2（移植底本） | 12 | 11 | 看板 | **8.3%**（1/12） | 4.5%（1/22） |
| `breast-cancer-workbench` v0.3（成熟基准，26 号口径） | 8 | 11 | 看板 | **12.5%**（1/8） | 5.6%（1/18） |
| 两基准合并去重 | 15 | 11 | 看板 | **6.7%**（1/15） | — |

**判定：✅ 通过**（阈值 ≤70%，实测最高 12.5%）。

**语义近似（诚实披露，不藏）**：5/11 条与基准"功能同域、名称不同"——复诊与随访≈复诊准备、试验与线索≈临床研究、心理与家庭≈心理支持、资料与导出≈病情整理、指标与报告≈检查与指标。它们名称不同不是文字游戏，而是**二级结构与内容不同**（见 §3 逐条）。剩余 6 条为本癌种独有拆分。

## 2. 实测方法与原始数据

```text

计算：逐字相同的一级名称数 ÷ 基准一级数；Jaccard = |交集| ÷ |并集|
复核：M2 走查脚本 `scripts/check-diff-matrix.mjs` 断言一致率 ≤70%（数值取自原型 DOM 与本文档）
```

## 3. 差异化矩阵（场景 → 功能 → 怎么验）

> 每条都必须能落成**断言**；落不成断言的不算差异化，只算文案差异。

| # | 场景（患者处境） | 功能 | 怎么验（可执行断言） |
| --- | --- | --- | --- |
| **D1** | 拿到写满亚型/分级/分子的病理报告，"不知道该看哪一句" | **亚型档案卡**：一条病理 = 一张卡，四段固定（亚型/分级/部位与深浅描述/分子+免疫组化），每段带医生原文与出处；**无推断** | ① schema 断言 `pathology` 表无 `diagnosis`/`risk_level`/`stage_group_auto` 列；② 写入一条只含"未写明分级"的记录 → 界面显示"报告未写明"而非默认值；③ 全仓 grep「考虑为」「提示为」「属于低危」= 0 命中 |
| **D2** | "同一个病，长在腿上和长在肚子后面，复查完全不一样" | **部位分轨**：每条影像/治疗记录必带 `site`+`depth`；同指标不同部位**不进同一条趋势**；随访日历按部位分节（`*_title`） | ① 构造两条同日期不同 `site` 的影像记录 → 断言渲染在两个分节标题下；② 趋势查询 SQL 必带 `site` 过滤（单测断言 SQL 含 `site = ?`）；③ 缺 `*_title` 时 check 失败 |
| **D3** | "我做了手术、也做了放疗、还进了组，三样是并行的" | **局部/全身双轨并行**（32 号折叠卡）：手术+放疗一轨、化疗/靶向/试验一轨，同期允许，各自折叠卡收/展 | ① demo 构造"术后辅助化疗 + 同期放疗" → 断言两卡同处"进行中"且不互相覆盖；② 折叠卡收/展两态截图 ≥2 张（33 号）；③ DOM 断言每卡有 `aria-expanded` 两态 |
| **D4** | "复查就是反复 MRI 和胸部 CT，我不知道哪次是基线" | **影像基线锚点**：最多一条激活基线；每次影像只记"对照哪次"+报告原文；**不自算变化率、不判进展** | ① `imaging` 表无 `recist`/`response`/`progression` 列；② 尝试设第二条基线 → 断言旧基线自动失活且库内激活数恒为 1；③ 无基线时页面显示"尚无基线"占位而非空图/0 值 |
| **D5** | "换医院时抱一摞报告，医生翻五分钟就放下" | **一页时间线导出**：亚型 + 局部/全身双轨 + 基线影像 + 指标表；私密与演示数据默认排除 | ① 导出物断言含四个区块标题且**不含** `private` 条目文案；② 代码级三出口过滤（导出/AI/摘要）共用同一函数，单测覆盖三处；③ 导出文件名带日期，正文带"资料截至" |
| **D6** | "我这型很少见，本地医生也没经验，想找研究" | **亚型/部位过滤的试验检索**：四通道 MCP stdio，逐条带 `source`+`fetched_at`；失败显示"未查过/未取回" | ① `manifest=jsonl=sqlite` 三处计数相等断言；② 通道失败用例注入 → 界面显示"未取回"且不渲染空列表；③ 解析器对空/错误响应的降级单测 |

## 4. 与三个最近邻仓的正向区分（写清"为什么不是它们"）

| 最近邻 | 像在哪 | **差在哪（本项目独有）** |
| --- | --- | --- |
| **GIST**（胃肠间质瘤） | 同为间叶源性肿瘤、有靶向治疗 | GIST 是**单驱动 + 单标准一线**（KIT/PDGFRA → 伊马替尼），路径收敛；STS 是**亚型 × 部位 × 分级三维发散**，本仓因此不做"标准路径"页，改做"亚型卡 + 并行轨道" |
| **胃癌/食管癌** | 同属"治疗线 + 随访"结构 | 消化道癌的主轴是**进食与营养**；STS 的主轴是**部位与功能（保肢/淋巴水肿）**，营养在本仓被显式降级（SPEC §3.2） |
| **肾癌** | 晚期有 TKI/IO 趋势线 | 肾癌有**可贯穿的指标**（肌酐/eGFR）与影像主线；STS 没有贯穿指标，故**不做一图秀**，改做基线锚点 + 原文对照 |
