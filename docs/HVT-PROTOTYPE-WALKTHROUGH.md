| 宫颈有、本仓没有 | 为什么不设 |

| 我的分期（独立一级） | STS 分期组依赖部位，独立成页会诱导患者自己算（ADR-2）；并入「我的亚型 · 分级与部位」 |

## 四、X3 通道一致性

- AI 按钮统一走 `data-action="agent-draft"`，点击后**只把提示词放进候选区**并 toast "未自动发送（IP10）"，不触发任何发送。
- 候选区显示 `AI 候选（未确认）` + `待核对` 徽标 + 「确认 / 不对，改一下 / 全部拒收（零副作用）」。
- 手工通道统一收在卡片 `⋯ 更多`，内含"手工补一条 / 改这一条 / 看原文"，与 AI 通道写同一实体（IP9）。
- 导出与摘要共用 `visible()` / `exportable()` 两个函数（app.js 顶部），私密三出口代码级过滤（R7）。
