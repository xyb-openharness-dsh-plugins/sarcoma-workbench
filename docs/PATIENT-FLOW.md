# 患者流程（PATIENT-FLOW）· 软组织肉瘤 v0.1

> 三条路径都由「患者在什么时刻最难受」反推页面树，不从医生流程照搬。
> **场景均为假设，标〔待访谈核实〕**——本轮 0 访谈，六条假设见 `SCENARIOS.md`。
> 事实依据见 `research/STS-FACTCHECK-2026-10-25.md`；引用版本：NCCN STS V3.2026 / AJCC 8 / WHO 5th（2020）。

## 路径 A · 非计划切除之后（最痛的一条，肉瘤独有）〔待访谈核实〕

```
腿上有个不痛的肿块，在县医院当脂肪瘤切了。两周后病理回报"恶性"，
医生说要再切一次、范围要大得多。患者手里只有一张病理报告和一句"尽快来大医院"，
说不清第一次是哪天切的、切的什么、现在该问什么。
```

1. **打开「确诊路径 → 时间轴」** → 依次补：肿块发现日 / 首次就诊日与科室 / 活检日与方式 /
   第一次切除日与机构 / 病理回报日与原文亚型名。**只记日期与名称，不评价"当初该不该切"。**
2. **进「确诊路径 → 活检与病理会诊」** → 记下"病理送了哪家会诊、结论原文怎么写的"。
   （WHO 2020 有 50 余种恶性亚型，会诊是常规流程——这句是解释层，可写；"你的亚型是凶的"不许写。）
3. **进「我的肿瘤 → 部位与大小」** → 记肿瘤部位（大腿）、大小数值（抄影像/病理原文）、深度描述。
4. **进「复查与随访 → 问题清单」** → 勾选想问的：「第二次要切多大范围」「切缘怎么算够」
   「要不要放疗、术前还是术后」——**产品只整理成清单，不生成答案。**
   **产物**：一条完整的时间轴 + 一页能带进诊室的问题清单。

## 路径 B · 肢体术后康复 + 复查前〔待访谈核实〕

```
保肢手术后三个月，能走路但蹲不下去、小腿肿。复查前想知道上次影像什么时候做的、
这次要查什么、为什么每次都拍胸片不拍腿。
```

1. **打开看板** → 「今日一页」显示：距上次影像多久、下次复查参考节点（按自己记的节奏推算）、
   当前康复记录条数。
2. **进「功能与康复 → 日常动作」** → 补三条自述：「蹲不下去」「走 500 米要歇」「小腿傍晚肿」。
   **是患者自己的话，不是评分。**
3. **进「功能与康复 → TESS 自评」** → 记"哪天填的、下肢 30 题的原始作答"。
   **不显示总分、不画趋势、不写"比上次好/差"。**（MSTS 是医生填的，产品不给这个入口。）
4. **进「复查与随访 → 影像时间轴」** → 看到每次影像的日期、部位、方式。**并列摆放，不连成"生长曲线"。**
5. **进「复查与随访 → 随访节奏」** → 并列 NCCN V3.2026 原表对应那一档的原文
   （机构 + 版本 + 表号；页码待核）+ 三条脚注原文（易于体格检查的部位可能不需要影像 /
   10 年后复发可能性小、随访应个体化 / 高分化脂肪肉瘤不需常规胸部影像）。
   **产物**：功能自述 + 影像时间轴 + "为什么这次查这些"的解释 + 问题清单。

## 路径 C · 晚期 / 不可切除，系统治疗中〔待访谈核实〕

```
腹膜后肉瘤术后复发，医生说不能切了，开始吃药。患者记不住第几个周期、
这两周的手脚反应是哪天开始的，也不知道下次评估在什么时候。
```

1. **打开看板** → 当前方案名（标「获批状态未核实」）、第几周期、距下次评估天数。
2. **进「治疗与线序 → 线序时间轴」** → 一线/二线的起止日期、方案名、换线原因（抄医嘱原文）。
3. **进「副作用与不适 → 副作用记录」** → 按日期补：手脚皮肤反应、乏力、食欲；
   每条可并一张同日化验（**并置不并轴**，用户自己看到，"因为血小板低所以减量"这类因果句一句不生成）。
4. **进「副作用与不适 → 该联系谁」** → 只列用户在设置里自己填的联系人与观察项，
   **产品不给"什么情况必须去医院"的阈值判断**。
5. **进「生活与照护 → 异地就医与资源」** → 记在哪家看的、是否经过 MDT、花费金额。
   **"要不要换家医院"不生成。**
   **产物**：一页复诊摘要（线序 + 最近化验 + 副作用 + 问题清单）。

## 页面树反推

| 一级页 | 由哪条路径反推 | 不建会怎样 |
| --- | --- | --- |
| 看板 | A/B/C 都要 | 每次都要从头翻 |
| 我的肿瘤 | A（报告看不懂）/ C | 亚型、部位、分期、分级四个词混在一起 |
| 确诊路径 | A | 非计划切除的患者说不清"到底经历了什么" |
| 手术与伤口 | A/B | 切缘与伤口恢复无处放 |
| 治疗与线序 | C | 晚期说不清用过哪些方案、第几周期 |
| 副作用与不适 | C | 副作用只散在记忆里 |
| 功能与康复 | B | 术后"蹲不下去"这种真实受限没处记 |
| 化验与指标 | C | 单点数值没有位置 |
| 复查与随访 | A/B/C | 节奏与问题清单无处生成 |
| 影像与报告 | B/C | 影像报告原文丢了 |
| 生活与照护 | A/C | 异地就医与花费无处记 |
| 临床研究 | C（"医生提到某个试验"） | 罕见病试验线索无处放 |
