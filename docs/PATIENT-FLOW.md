# 软组织肉瘤工作台 · 患者旅程（PATIENT-FLOW）v0.1

> 状态：草案（G1 待签认）。**0 访谈**：本图由「疾病轴 + 公开患者叙述 + 家族经验」推导，属**假设模型**，不是已确认的真实旅程。
> 用法：每个阶段写清「患者此刻在怕什么 / 手里有什么纸 / 工作台接住哪一页」。接不住的阶段要么补功能，要么写进"明确不做"。

## 0. 一句话旅程

```text
摸到包块 → 挂号/影像 → 穿刺或切除活检 → 拿到病理（亚型+分级）→ 分期与多学科讨论
   → 手术（±重建）→ 放疗（术前/术后）→ 化疗/靶向/试验 → 复查（原发部位+肺）
   → 复发/转移 → 再治疗/换线 → 长期随访与功能康复
```

与癌（carcinoma）不同，STS 的**确诊路径常从"以为是个脂肪瘤"开始**，患者第一次听到"肉瘤"时通常毫无准备；且**治疗从第一天起就是局部与全身两条线并行**，不是排队。

| P10 | 家庭与生育 | "还能要孩子吗？家里怎么撑？" | 生育保存咨询单 | 「心理与家庭 · 生育与亲密（私密）」 | 不代替遗传咨询 |

## 2. 三个关键转折点（决定工作台结构）

1. **P2 拿到病理**：这是患者第一次接触"亚型"概念，也是**信息落差最大**的一刻。工作台的第一价值不是"记录"，是**把报告上的词接住**。
2. **P4→P7 局部到随访**：手术与放疗结束后，患者进入"每 3–6 个月复查"的长周期。此时的核心问题从"怎么治"变成"这次和上次比"——**基线锚点**因此成为独立功能。
3. **P8 复发/换线**：治疗从单轨变成多轨叠加（既往手术 + 新放疗 + 二线药 + 试验）。**并行轨道**模型在这里被真正使用。

## 3. 双主体差异（患者 vs 家属代记）

| 阶段 | 患者本人 | 家属代记 | 工作台差异 |
| --- | --- | --- | --- |
| P2 病理 | 想自己看懂 | 想替老人记住 | 代记标记 + 大字模式 |
| P4 手术 | 关心保肢与外观 | 关心护理与住院安排 | 同一记录，两种摘要视图 |
| P8 复发 | 情绪冲击最大 | 要协调转诊与费用 | 心理线私密默认对家属关闭 |
| P10 生育 | 本人议题 | 常不涉及 | 私密，代记者默认不可见 |

## 4. 旅程里**不接**的四件事（写下来才算决定过）

1. 筛查与自查指导（P0）：不做，避免制造焦虑与延误就诊。
2. 分期结论（P3）：不做，医生任务。
3. 预后与生存期（P8）：不做，任何数字都会被误读。
4. 康复承诺（P9）：不做"练多久能恢复"，只记录与并列。
