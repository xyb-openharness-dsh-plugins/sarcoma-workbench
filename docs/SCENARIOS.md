## S01 病理报告看不懂

- **患者原话（假设）**："报告上写'滑膜肉瘤，双相型'，我搜了一晚上，越搜越怕，也不知道该看哪一句。"
- **页面接住**：我的亚型 → 病理原文。一张卡分四段：亚型名称 / 分级 / 部位与深浅描述 / 分子与免疫组化，每段只显示**报告原文 + 出处（哪家医院、哪份报告、日期）**；卡背面是"这个词在报告里是什么位置"的解释。
- **明确不做什么**：不解释"双相型意味着预后更好/更差"；不推荐治疗方案；不做亚型自动识别。

## S02 分子/免疫组化一堆缩写

- **患者原话（假设）**："SS18-SSX、INI1、MDM2、CD34……医生说是做检测，可我不知道这些是查什么的。"
- **页面接住**：我的亚型 → 分子与免疫组化。每个缩写一行：**检测名称 / 结果 / 检测方法 / 报告原文**，并挂一条中性说明（"这是病理科用来辅助分类的检测项"），不解释治疗意义。
- **明确不做什么**：不说"有靶点就能用某药"；不把分子结果推成亚型结论。

## S03 分级与分期被自己混算

- **患者原话（假设）**："医生说我 G2、II 期，我以为数字越大越重，后来才知道分级和分期不是一回事。"
- **页面接住**：我的亚型 → 分级与部位。**两栏并列**：左"报告写的分级（G1/G2/G3/未分级）"，右"报告写的分期（含部位）"，中间一行固定提示"分级是显微镜下的恶性程度，分期是病变范围，两者不能互相换算"。
- **明确不做什么**：不计算分期；不给"你的分期属于哪一组"；不显示生存率。

## S04 想去另一家医院会诊

- **患者原话（假设）**："我想去北京再看一次，可我不知道该带哪些片子、该问什么。"
- **页面接住**：我的亚型 → 会诊与二次意见。清单：要带的资料（病理切片/白片、影像光盘、报告原件）、已问过的问题、两家医院结论差异的**原文并列**。
- **明确不做什么**：不评价哪家医院更好；不建议"应该去会诊"。

## S05 术后复查，不知道哪次是基线

- **患者原话（假设）**："每次复查都说'和上次比'，可我根本不知道哪次算'上次'。"
- **页面接住**：影像与基线 → 基线锚点。一个显式按钮"把这次设为基线"；全库只有一条激活基线；每次影像卡显示"对照：2026-03-12 术后 MRI（基线）"。
- **明确不做什么**：不自算病灶变化率；不判断"稳定/进展"。

## S06 新影像报告想和上次对照

- **患者原话（假设）**："这次报告写'较前增大'，可上次也这么写，我到底是在变好还是变坏？"
- **页面接住**：影像与基线 → 复查记录 / 报告原文对照。同一部位按时间倒序列出报告原文，两两并列"这次原文 vs 上次原文"，中间显示间隔月数。
- **明确不做什么**：不解释"增大多少算进展"；不把文字描述转成 RECIST。

## S07 手术切缘与伤口问题

- **患者原话（假设）**："出院记录写'切缘阴性'，可伤口一直渗液，我不知道这算不算没长好。"
- **页面接住**：局部治疗 → 手术记录 / 切缘与并发症。手术记录含日期、术式原文、切缘原文；并发症单独记（渗液/感染/血肿），只记自述与换药次数。
- **明确不做什么**：不判断伤口是否感染；不说"切缘阴性就安全"。

## S08 放疗期间皮肤反应与疲劳

- **患者原话（假设）**："放疗到第 15 次，皮肤又红又疼，是不是得停？"
- **页面接住**：局部治疗 → 放疗疗程（次数、部位、总剂量原文）+ 功能与康复 → 伤口与皮肤（每天可记一句 + 拍照可选，本机存）。
- **明确不做什么**：不做放射性皮炎分级；不说"要不要停"。

## S09 化疗周期与血象低

- **患者原话（假设）**："我是第 3 周期第 8 天，白细胞 2.8，是不是不能打下一次了？"
- **页面接住**：全身治疗 → 周期与用药（方案原文、周期号、给药日）+ 指标与报告 → 血象（数值 + 参考范围 + 日期 + 化验单出处）。
- **明确不做什么**：不做 CTCAE 自动分级到"该不该化疗"的推断；不给升白建议。

## S10 换线：为什么换、换成什么

- **患者原话（假设）**："医生说要换药，我问为什么，他说'进展了'，可我连之前用的是什么都记不清。"
- **页面接住**：全身治疗 → 换线记录。每条换线含：停用方案、新方案、**医生原话原因**、日期；治疗线总览按时间列出所有线，标注"进行中/已结束"。
- **明确不做什么**：不把"进展"扩写成解释；不推荐下一线。

## S11 腿肿、走不远

- **患者原话（假设）**："手术后这条腿一直肿，走路十分钟就沉，是不是以后都这样？"
- **页面接住**：功能与康复 → 淋巴水肿（腿围/臂围数值 + 测量位置 + 日期）、肢体功能（活动度/辅助器具/步行距离自述）。
- **明确不做什么**：不做淋巴水肿分期；不承诺康复效果。

## S12 肝肾功能指标异常

- **患者原话（假设）**："化验单上 ALT 高了 3 倍，医生只说'观察'，我心里没底。"
- **页面接住**：指标与报告 → 肝肾与心肌（数值 + 参考范围 + 日期 + 出处）；趋势对照只在**同一指标同一单位**下画线，跨单位不合并。
- **明确不做什么**：不做 ×ULN 分级到"严重程度"的结论；不给停药建议。

## S13 复诊前不知道问什么

- **患者原话（假设）**："每次进诊室就懵，出来才想起来要问的三个问题一个没问。"
- **页面接住**：复诊与随访 → 待办与问题（可编辑清单，按优先级排序）+ 就诊准备（一页纸：亚型、最近治疗、最近影像、想问的 3 个问题）。
- **明确不做什么**：不生成"医生一定会回答"的话术；不承诺问题会被采纳。

## S14 找临床试验

- **患者原话（假设）**："我这个亚型很少见，本地医生也没经验，我想看看有没有正在做的研究。"
- **页面接住**：试验与线索 → 检索入口。按亚型/部位筛选，列出登记号、标题、地点、状态、**检索出处与时间**；点开是原文摘要。
- **明确不做什么**：不推荐入组；不判断是否符合条件；不把"招募中"说成"适合你"。

## S15 害怕复发、家里撑不住、生育

- **患者原话（假设）**："我不敢跟家里说我在查复发的事，也想知道以后还能不能要孩子。"
- **页面接住**：心理与家庭 → 当下感受（情绪词 + 一句自述，私密）/ 私密记录（默认不导出、不进摘要）/ 支持资源（公开可查的机构）/ 生育与亲密（治疗前咨询记录，私密）。
- **明确不做什么**：不做心理量表评分；不做危机分级；出现自伤表述时只给"联系当地急救或治疗团队"的固定提示，不展开。

## S16 把资料整理给医生

- **患者原话（假设）**："换医院时，我抱着一摞报告，医生翻了五分钟就放下了。"
- **页面接住**：资料与导出 → 导出快照。选时间范围与内容，生成一页 Markdown/PDF（含亚型、治疗线、基线影像、指标表），**私密内容默认排除**、演示数据默认排除、导出文件带"生成于 X，资料截至 Y"。
- **明确不做什么**：不生成"诊断结论摘要"；不把导出物说成病历。
