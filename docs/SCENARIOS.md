## 一图秀断言（按家族合同）

- 单调三次插值（Fritsch-Carlson），末点按 y 排 13px 避让；
- 事件竖虚线（手术日 / 活检日 / 病理回报日 / 方案开始）**上端止于 CY0-10**；
- 分类序列（术式 / 亚型 / 影像方式 / 切缘）只画节点不连线；
- 卡背迷你折线；单点写「只有 1 次记录，暂不连线」；
- 关治疗节点不改曲线（事件只做竖线，不插值成折点）。
