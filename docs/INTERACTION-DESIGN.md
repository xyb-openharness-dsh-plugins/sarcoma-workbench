# 小肉宝 SarcoPal 交互路径设计（INTERACTION-DESIGN）v0.1

> 状态：**草案，G1 同批签认**（与 SCENARIOS、页面树一起签）。
> 判据来源：starter `docs/28-INTERACTION-PATH-DESIGN.md`（IP1–IP10）与 `skills/hvt-requirement-review/references/interaction-path-consistency.md`（X1–X4）。
> **本表未签认不开 HTML 原型（IP1）**；G2 走查按本文逐条断言。

## 一、总原则

- AI 协助默认：说 / 拍 / PDF → 结构化候选 → 逐项核对 → 确认才入事实层；拒收零副作用。
- 手工永远可及但收敛：入口收在卡片「⋯ 更多」；每页显式编辑 ≤1；表单 ≤6 字段；数字用键盘组件。
- 删除 = 更正：只新增版本；界面语言"改这一条"；全站无"不可恢复"。
- 回首页一步：二级页返回 / 顶栏品牌 / 完成 Toast 内嵌"回到看板"。
- 双主体：代记条目逐条显示"谁记的"；私密条目默认不进导出/摘要/AI 上下文。

## 三、CRUD 双通道矩阵（每个可写实体一行）

| 实体 | AI 协助（默认） | 手工（收敛入口 / 字段数 ≤6） | 说明与红线 |
| --- | --- | --- | --- |
| `pathology` 病理/亚型 | 拍/PDF → 亚型/分级/部位/分子候选 | 「⋯ 更多」补一条（亚型/分级/部位/深浅描述/日期/出处） | 只照录；不推断亚型；分级可"未写明" |
| `imaging` 影像 | 拍报告 → 部位/模态/日期/原文候选 | 补一条（部位/模态/日期/是否基线/对照哪次/原文） | 不判进展；基线最多一条 |
| `treatment_local` 局部治疗 | 拍出院/放疗单 → 术式/切缘/次数候选 | 补一条（类型/起止/详情/切缘/状态） | 切缘只照录；不解释 R0/R1 |
| `treatment_systemic` 全身治疗 | 拍化疗单 → 方案/周期/日期候选 | 补一条（方案/周期/起止/状态/原因原文） | 换线必填医生原话；不推荐下一线 |
| `function_log` 功能记录 | 说一句 → 描述候选 | 补一行（领域/描述/数值/单位/日期） | 不做淋巴水肿分期；不承诺恢复 |
| `metric` 指标 | 拍化验单 → 指标/值/参考范围候选 | 补一行（名称/值/单位/参考范围/日期） | 不做 CTCAE 推断到处置；跨单位不合并 |
| `visit` 复诊 | 说/写 → 目的与问题候选 | 补一条（日期/目的/问题/小结） | 不生成"医生会说" |
| `bioProfile` 建档 | 拍病理/分子报告 → 地区/亚型/分子/IHC 候选（**三态**：已知/未测/本癌种无此项） | 「⋯ 更多」补一项（项名/值/来源/日期 ≤6 字段） | 未测不写成阴性；不推断分型 |
| `trial` 试验 | **—（红线：试验条目不得 AI 生成，只从登记库取；匹配指数由 `match.js` 算，不由模型算）** | 手工收藏（登记号/标题/来源） | 不输出"能入组/符合条件/建议报名"；`index=null ≠ 0`；显示采集时间与通道终态 |
| `viewpoint` 心理/私密 | 说一句 → 情绪词+自述候选（private） | 选情绪词 + 一句（≤140 字） | 不做量表评分/危机分级；默认不导出 |
| `document` 资料 | 上传 → 解析候选 | 上传 + 备注 | 原件不改动；解析失败零候选 |
| `candidate` 候选 | 由上面各通道产生 | 「逐项核对」改/删 | 拒收零副作用；不落"已保存" |

不做 AI 通道的实体写"—"并写明红线理由（`trial`）；其余实体 AI 默认、手工可及。
