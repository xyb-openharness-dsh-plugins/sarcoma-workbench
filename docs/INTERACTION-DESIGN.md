## 一、总原则

- AI 协助默认：说 / 拍 / PDF → 结构化候选 → 逐项核对 → 确认才入事实层；拒收零副作用。原型只在「影像与报告 → 资料整理」实现了这条闭环，其余实体的现状见 §三 3.2 与 §四。
- 手工永远可及但收敛：「⋯ 更多」收口；每页显式编辑 ≤1；表单 ≤6 字段；数字用键盘组件。原型现状与这条的差距见 §三 3.2。
- 删除 = 更正：只新增版本；界面语言「改这一条」，无「不可恢复」。原型现状见 §三 3.2。
- 回首页一步：一级导航「看板」/ 二级页返回 / 整页视图关闭。看板是 12 个一级页中的第 1 项，点击即回顶部。
