# 小韧宝 SarcPal 整页视图清单（项目实例）

> 通用规范见 `docs/32-FULL-PAGE-VIEW.md`；可运行实现见 `assets/patterns/page-view.js`。
> 本文件只填**本项目有哪些整页、从哪进、退到哪**。
> 状态：M4 起执行。A1–A10 逐条有证据后才算完成。

日期：2026-10-25。实现入口：`prototypes/v0.2/`。页面树来源：`docs/DIFF-MATRIX.md` §页面树（12 一级页 / 36 页签）。

## 1. 形态判定

判据只有一条：**预计内容高度超过 1.5 屏，或需要内部多区块切换 → 整页**。

| 交互 | 形态 | 判定理由 |
| --- | --- | --- |
| 删除一条记录 / 清空演示数据 | 弹窗 | 一句话确认 |
| 改一个日期 / 选一个部位 / 改一个数值 | 弹窗 | 3 行以内 |
| 字号三档 / 面板宽度 / 关于 / 版本 | 弹窗 | 设置项，不承载内容 |
| 任意一条**记录详情**（病理 / 影像 / 化验 / 手术 / 放疗 / 副作用 / 功能） | **整页** | 要同时放值、日期、谁说的、报告原文、来源回链 |
| **报告原文**（从记录详情再点开） | **整页 L2** | 连续阅读，长文本；不能压在详情下面滚 |
| 新增 / 编辑**手术档案**（多字段 + 切缘 + 伤口） | **整页** | 字段多，一屏放不下 |
| **TESS 逐题作答** | **整页** | 题量大，中途返回不许丢答案 |
| **一图秀**放大 | **整页** | 宽度就是可读性 |
| **随访节奏**（NCCN 五档原表 + 脚注） | **整页** | 表格宽，脚注必须同屏可见 |
| **线序时间轴**全景 | **整页** | 横向密度 |
| **临床试验详情** | **整页** | 卡片四块 + 历史数据 + 出处 |
| **资料整理**（上传 → 解析候选 → 逐项核对 → 入库） | **整页** | 四步一条链，弹窗放不下第 3 步 |

保留为弹窗的共 **4** 类，全部是不承载内容的短交互。

⚠️ 自查：肾癌样板里「用药与副作用 → 副作用详情」「影像与报告 → 报告原文」原本是弹窗。肉瘤**不继承这个做法**，直接按整页做——报告原文是肉瘤患者最常反复读的东西（术前病理、术后病理、会诊意见三份要对着看）。

## 3. 导航与 history

| 项 | 本项目口径 |
| --- | --- |
| 压栈方式 | `pv.open(key, params)`，`params` 只带 `{type, id}` 这类标识，不带整条记录对象（避免与读模型两套形状） |
| Esc 语义 | 深 1 层 = 关闭；深 ≥2 层 = 退一层 |
| 浏览器返回键 | 等价 `back()`，由 `page-view.js` 内建，本项目不改写 |
| 深链 | `#page=record&type=pathology`（参数走 `params`，URL 只带 key 与 type） |
| 关掉后焦点 | 回到触发元素；列表项是 `<button>`，不是 `<div onclick>` |
| 主页滚动位置 | 返回时恢复 |

## 4. 每页分区

| key | 分区 | 放什么 | 原来在哪 |
| --- | --- | --- | --- |
| `record` | 事实 / 原文 / 来源 / 关联 | 值+日期+谁说的；原文块；来源回链；关联的同日记录 | 弹窗里被压成 3 行 |
| `report` | 原文 / 出处 / 免责 | 报告原文照抄（不改写、不摘要）；机构+检查日期 | 无处可放 |
| `surgery` | 术式 / 日期 / 医院 / 切缘入口 | 手术档案字段 + 跳「切缘记录」 | 弹窗放不下 |
| `margin` | 原文 / 谁报的 / 与手术的关系 | 只抄 R0/R1/R2 或定性描述原文 | 无 |
| `wound` | 时间序列 / 每次记录 / 照片位 | 伤口状态历次记录 | 无 |
| `tess` | 分肢体 / 逐题 / 保存状态 | 原始作答（**不给总分、不画趋势**） | 无 |
| `chart` | 图 / 指标区 / 治疗条 / 图例 | 一图秀全宽版，R1–R12 一条不放宽 | 弹窗里图表被压扁 |
| `cadence` | 五档表 / 三条脚注 / 我的位置 | NCCN V3.2026 随访原表 + n/o/r 脚注原文 | 无 |
| `timeline` | 线序 / 周期 / 放疗条 | 横向时间轴，事件竖虚线上端止于 CY0-10 | 无 |
| `trial` | 属性 / 原理 / 阶段 / 历史数据 | 药物卡片四块（机制未披露必须写「未披露」） | 无 |
| `intake` | 上传 / 解析候选 / 逐项核对 / 入库 | 四步链路，候选与业务事实分表 | 无 |
